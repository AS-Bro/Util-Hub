Privacy & How It Works

What happens to your files, text, and browser requests when you use Utility Hub.

Processing on your device

Most tools process text and files in your browser. The QR Code Generator also builds and exports QR codes locally using a library bundled with this site. Utility Hub does not upload files for processing.

Tools that load remote images

Image URL & Clipboard Downloader requests the image URL you enter directly from that image host. The host can see the request and your IP address; the image is not uploaded to Utility Hub.

Social Media Post Previewer loads the preview media and avatar URLs in your browser, including its sample image from images.unsplash.com. If you leave the avatar URL blank, the displayed author name is sent as a query parameter to ui-avatars.com to generate the default avatar.

Family Tree loads a remote image if you add an avatar URL to a person. Other family-tree content remains in your browser storage.

Third-party resources

Some pages load fonts, styles, or libraries from Google Fonts (fonts.googleapis.com and fonts.gstatic.com) and CDNs such as cdnjs, jsDelivr, unpkg, and Tailwind’s CDN. Those providers may receive your IP address and normal browser request metadata. The libraries process the tool data locally in your browser.

Browser storage

Favorites, recent tools, and your theme preference are stored in this browser’s localStorage. Some tools also save their own settings or working data there. This storage is not sent to Utility Hub by the site.
